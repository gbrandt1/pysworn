# Sworn Script Language

Sworn is a script language to play the Ironsworn:Starforged family of games. It is based around the [datasworn](https://github.com/rsek/datasworn) format.

## Acknowledgements

The interpreter is implemented in Python and takes heavy inspiration from
[pylox](https://github.com/sco1/pylox), a Python implementation of [lox](https://github.com/munificent/craftinginterpreters).
