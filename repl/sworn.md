# Sworn Language Reference

## Examples

$ view truth medicine

## Tokens

- keywords
  - pragmas
    - play [rulesetN] ... [ruleset1] # which rulesets to load
    - seed [int]
  - rules
    - action_roll
    - progress_roll
  - macros
    boost
- reference ids
  - --> built from included rulesets
- variables
  - "\[a-z]\[A-Z][0-9]"
- constants
  - string ["..."]
  - markdown ["""..."""]
