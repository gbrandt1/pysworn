## Tokens

- keywords
  - pragmas [ ] move to configuration
    - play [rulesetN] ... [ruleset1] # which rulesets to load
    - seed [int] # initialize random number generator
    - match [fuzzy|exact] # how to match rules
  - rules
    - action_roll
    - progress_roll
  - macros
    boost
- reference ids
  - --> built from included rulesets
- variables
  - "\[a-z]\[A-Z][0-9]"
- constants
  - string ["..."]
  - markdown ["""..."""]
